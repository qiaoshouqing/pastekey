<h1 align="center">PasteKey</h1>

<p align="center"><b>お気に入りのプロンプトを、ワンキーで。</b><br>ChatGPT、Claude、Cursor などどのアプリにも、保存したプロンプトをすぐ貼り付けられる macOS メニューバーアプリです。</p>

<p align="center"><a href="README.md">English</a> · <a href="README_zh-Hans.md">简体中文</a> · <a href="README_zh-Hant.md">繁體中文</a></p>

---

- **どこでも ⌥ Space**：Spotlight のようなパネルでプロンプトを検索し、Return でカーソル位置に貼り付け。
- **プロンプトごとのショートカット**：よく使うものに ⌃⌥1 などを割り当てて即貼り付け。
- **プロンプトマーケット**：研究・執筆・コーディングなど 7 カテゴリ、24 本の厳選プロンプト（英語・中国語）。カタログはこのリポジトリから自動更新。
- **変数**：`{{clipboard}}`・`{{input}}`・`{{date}}`・`{{time}}` を貼り付け時に置き換え。
- **クリップボードを保持**：貼り付け後、元のクリップボードを復元。

[Releases](https://github.com/qiaoshouqing/pastekey/releases/latest) から `PasteKey-1.0.0.dmg` をダウンロード。Apple の公証済み、macOS 13 以降。自動貼り付けには「システム設定 › プライバシーとセキュリティ › アクセシビリティ」で PasteKey を許可してください。
